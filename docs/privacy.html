PRIVACY POLICY

隐私政策

本政策说明日语汉字 AI 读音助手（以下简称“本扩展”）处理哪些数据、为何处理，以及你如何控制或删除这些数据。

生效及最后更新日期：2026 年 8 月 22 日

1. 单一用途

本扩展用于在日语网页的汉字上方显示读音、在高置信片假名外来语上方显示外语原词，并在用户主动选择文字后，通过用户自行配置的 OpenAI 兼容接口提供翻译。扩展不会将这些能力用于广告、画像、数据销售或与阅读辅助无关的目的。

2. 本地处理的数据

  • 网页正文会在浏览器内进行日语形态分析，以生成读音；正文不会因此发送给开发者服务器。
  • 片假名外来语会与扩展安装包内的固定词源子集和人工常用修正进行本地匹配；该功能不会查询远程词典或调用翻译 API。
  • API Key、BaseURL、模型、目标语言和界面语言保存在本机的 Chrome 扩展存储中。
  • 翻译历史可包含所选原文、译文、页面 URL、页面标题、时间、模型、目标语言及 Token 用量；Token 明细包含页面 URL、页面标题、时间及用量。上述记录保存在本机。

3. 发送给用户所选服务商的数据

只有在你主动发起翻译时，所选文字、目标语言和必要的请求指令才会发送到你配置的 API BaseURL。API Key 会作为认证信息随 HTTPS 请求发送给该服务商。点击“测试连接”时会发送固定测试文本“こんにちは”。本扩展不会把页面 URL、页面标题或本地历史附加到翻译请求中。

远程服务商会按其自身条款和隐私政策处理收到的数据。请只配置你信任的服务，并自行确认其保存、训练和跨境传输规则。非本机接口必须使用 HTTPS；仅 localhost 和 127.0.0.1 允许 HTTP。

4. 开发者不会收集或出售数据

本扩展没有开发者运营的数据接收服务器、分析 SDK 或广告 SDK。开发者不会接收、出售或向数据经纪商提供你的 API Key、网页正文、所选文字、浏览历史、翻译历史或 Token 记录。

5. 保存期限与删除

  • 设置和记录没有固定云端保存期限，因为它们只保存在本机浏览器中。
  • 翻译历史最多保留 500 条且受约 4 MiB 总量限制；Token 记录最多保留 1,000 条且受约 512 KiB 总量限制，超过限制时优先移除较旧记录。
  • 你可以在管理面板分别删除单条历史、清空全部历史、清空 Token 记录或清除 API Key。
  • 卸载扩展通常会移除 Chrome 为该扩展保存的本地数据；如需确保删除，请先在管理面板清空记录和密钥。

6. 权限用途

  • activeTab：仅在用户操作扩展时访问当前标签页。
  • scripting：向当前页面注入本地读音、外来语原词标注与划词翻译界面。
  • storage：在本机保存设置、历史与 Token 记录。
  • 可选主机权限：仅在保存或测试 API 配置时，为用户指定的接口来源申请网络访问；扩展不会预先取得固定的全站访问权限。

7. 安全边界

API Key 不会在管理面板或后台响应中完整回显，扩展存储被限制为可信扩展上下文访问。该机制用于减少意外暴露，但本机扩展存储并不是硬件保险库；请保护浏览器配置文件和设备账户，并在怀疑密钥泄露时立即到服务商处撤销或轮换密钥。

8. 儿童、变更与联系

本扩展不是面向儿童专门设计的服务，也不会主动建立用户账户。若功能或数据处理方式发生实质变化，本政策会同步更新日期和说明。隐私问题可通过公开项目的 GitHub Issues 提交。
