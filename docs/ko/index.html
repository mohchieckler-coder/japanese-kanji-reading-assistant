제품 소개

읽던 흐름을 끊고 검색하는 시간을 줄이세요

기존 리더를 대체하는 도구가 아닙니다. 현재 페이지에서 언제든 추가하거나 제거할 수 있는 가벼운 일본어 읽기 보조 도구입니다.

01

일본어 웹페이지 열기

일반적인 뉴스, 포럼, 학술, 스포츠 페이지에서 사용하세요. 페이지의 원문 전체나 링크를 대체하지 않고 현재 페이지에 읽기 도움을 바로 더합니다.

02

읽는 법 켜기

브라우저에서 텍스트를 로컬로 분석하고 표준 ruby 마크업으로 한자 위에 읽는 법을 표시합니다.

03

필요할 때만 번역하기

단어, 문장, 문단을 선택하면 탭을 계속 오가지 않고 같은 페이지에서 번역을 확인할 수 있습니다.

기능

실제 웹페이지를 읽는 데 맞춘 설계

일반 한자부터 외래어 원어, 뉴스 날짜, 이름, 긴 문장 번역까지 모든 기능이 원래 페이지 구조를 보존하도록 설계되었습니다.

01 · 스마트 읽기

한자마다 읽는 법을 위에 표시

Kuromoji가 브라우저에서 형태소 분석을 로컬로 수행합니다. 나중에 불러온 콘텐츠도 처리하며, 다시 클릭하면 확장 프로그램이 추가한 읽는 법을 제거합니다.

  • 코드, 양식, 기존 ruby 마크업은 건너뜁니다
  • 날짜, 외래어, 일반적인 문맥을 보수적으로 구분합니다
  • 한자에만 읽는 법을 달고 오쿠리가나는 그대로 유지합니다
  • 본문의 긴 읽기 표시는 크기를 자동으로 줄이고, 머리글과 탐색 영역의 읽기 표시는 항목 너비를 바꾸지 않습니다
  • 스타일과 상호작용을 보존하도록 요소 계층을 재배치하지 않습니다

02 · 외래어 원어

가타카나 위에 외국어 원어 표시

팝업에는 별도의 ‘외래어 원어 표시’ 버튼이 있습니다. 활성화하면 확장 프로그램에 포함된 3,353개의 로컬 어원 기록으로 신뢰도 높은 외래어를 대조하고, 잘 알려진 외국 정치 지도자·유명 인사·지명의 원어 표기를 보여 줍니다. API를 호출하거나 페이지 텍스트를 업로드하지 않습니다.

  • 영어 항목은 국가 표시 없이 원어만 보여 줍니다
  • 다른 언어는 仏, 独, 西 같은 일본어 한자 국가 약칭을 사용합니다
  • 긴 주석은 가타카나 본문의 너비로 접히며 너비가 제한된 팝오버에서 펼쳐집니다
  • 전체 고유명사는 직접 대조할 수 있지만 줄인 이름에는 직책·국가·인물 문맥이 필요합니다
  • 동형어, 와세이에이고, 알 수 없는 단어는 보수적으로 건너뜁니다

자주 묻는 질문

시작하기 전에 궁금할 만한 내용

이 확장 프로그램은 로컬 우선 방식이며 필요할 때만 연결하므로 읽는 법과 번역 기능을 서로 독립적으로 사용할 수 있습니다.

읽는 법 기능에 API가 필요한가요?＋

아니요. 한자 읽는 법은 브라우저에서 로컬로 분석됩니다. 선택 영역 번역에만 자신의 호환 API가 필요합니다.

확장 프로그램이 웹페이지 전체를 업로드하나요?＋

아니요. 읽는 법 주석은 네트워크를 사용하지 않습니다. 페이지 콘텐츠 중 사용자가 직접 선택한 텍스트만 설정한 번역 서비스로 전송됩니다. ‘연결 테스트’를 클릭하면 고정 문구 ‘こんにちは’가 전송됩니다. 제공업체는 자체 개인정보 처리방침에 따라 데이터를 처리합니다.

현재 페이지에서 읽는 법을 어떻게 제거하나요?＋

확장 프로그램 팝업을 다시 열고 ‘읽는 법 제거’를 클릭하세요. 확장 프로그램이 생성한 ruby 마크업을 제거하고 원래 텍스트를 복원하며 선택 영역 번역은 계속 사용할 수 있습니다. 매우 동적인 일부 페이지는 새로 고침이 필요할 수 있습니다.

일부 가타카나 단어에는 왜 원어가 표시되지 않나요?＋

가타카나는 와세이에이고, 의성어·의태어, 고유명사를 나타낼 수도 있습니다. 확장 프로그램은 2026-08-17 기준의 고정된 신뢰도 높은 JMdict 하위 집합, 수동 검토한 일반 단어 계층, 선별 검토한 일본 국립국어연구소 어휘 목록을 사용해 어원이 분명하고 검증된 단어에만 주석을 답니다. 항목 간 동형어, 알 수 없는 단어, 안전한 문맥이 없는 줄인 이름은 바꾸지 않습니다. 영어는 원어만 표시하고, 다른 언어와 외국 고유명사는 仏, 独, 西 같은 일본어 국가 약칭을 사용합니다.

아직 처리할 수 없는 페이지가 있나요?＋

Chrome 시스템 페이지에는 확장 프로그램을 삽입할 수 없습니다. 닫힌 shadow DOM, 교차 출처 iframe, 희귀 문자, 알 수 없는 고유명사는 바뀌지 않을 수 있습니다. 코드 블록, 양식, 기존 ruby 마크업, 편집 가능한 영역은 의도적으로 건너뜁니다.

번역 API는 무엇을 지원해야 하나요?＋

API가 POST /chat/completions를 지원해야 합니다. 일반 서비스는 HTTPS를 사용해야 하며 localhost와 127.0.0.1만 HTTP를 사용할 수 있습니다. 각 요청은 12,000자로 제한되며 사용자의 키, 네트워크, 할당량, 모델 접근 권한에 따라 작동합니다. 로컬 토큰 기록은 추정치이며 제공업체 청구 금액이 아닙니다.
