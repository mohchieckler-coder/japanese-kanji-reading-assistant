PRIVACY POLICY

개인정보 처리방침

이 방침은 일본어 한자 읽기 도우미(이하 ‘확장 프로그램’)가 어떤 데이터를 왜 처리하는지, 그리고 사용자가 이를 관리하거나 삭제하는 방법을 설명합니다.

시행 및 최종 업데이트: 2026년 8월 22일

1. 단일 목적

확장 프로그램은 일본어 웹페이지의 한자 위에 읽는 법을 표시하고, 신뢰도 높은 가타카나 외래어 위에 외국어 원어를 표시하며, 사용자가 텍스트를 직접 선택한 뒤 사용자 설정 OpenAI 호환 API를 통해 번역을 제공합니다. 확장 프로그램은 이러한 기능을 광고, 프로파일링, 데이터 판매 또는 읽기 지원과 무관한 목적으로 사용하지 않습니다.

2. 로컬에서 처리하는 데이터

  • 웹페이지 텍스트는 읽는 법을 생성하기 위해 브라우저에서 일본어 형태소 분석을 거칩니다. 이 과정에서 페이지 텍스트를 개발자 서버로 보내지 않습니다.
  • 가타카나 외래어는 확장 프로그램에 포함된 고정 어원 하위 집합 및 수동으로 선별한 일반 교정 데이터와 로컬에서 대조됩니다. 이 기능은 원격 사전을 조회하거나 번역 API를 호출하지 않습니다.
  • API Key, BaseURL, 모델, 번역 대상 언어, 인터페이스 언어는 Chrome 확장 프로그램 저장소에 로컬로 저장됩니다.
  • 번역 기록에는 선택한 원문 텍스트, 번역문, 페이지 URL, 페이지 제목, 시간, 모델, 번역 대상 언어, 토큰 사용량이 포함될 수 있습니다. 토큰 세부 정보에는 페이지 URL, 페이지 제목, 시간, 사용량이 포함됩니다. 이러한 기록은 로컬에 저장됩니다.

3. 사용자가 선택한 제공업체로 전송되는 데이터

사용자가 직접 번역을 요청할 때만 선택한 텍스트, 번역 대상 언어, 요청에 필요한 지침이 사용자가 설정한 API BaseURL로 전송됩니다. API Key는 HTTPS 요청의 인증 정보로 해당 제공업체에 전송됩니다. ‘연결 테스트’를 클릭하면 고정 테스트 문구 ‘こんにちは’가 전송됩니다. 확장 프로그램은 번역 요청에 페이지 URL, 페이지 제목 또는 로컬 기록을 첨부하지 않습니다.

원격 제공업체는 자체 이용 약관 및 개인정보 처리방침에 따라 수신한 데이터를 처리합니다. 신뢰하는 서비스만 설정하고 데이터 보관, 학습, 국외 이전 방침을 검토하세요. 로컬이 아닌 엔드포인트는 HTTPS를 사용해야 하며 localhost와 127.0.0.1만 HTTP를 사용할 수 있습니다.

4. 개발자는 데이터를 수집하거나 판매하지 않습니다

확장 프로그램에는 개발자가 운영하는 데이터 수신 시스템, 분석 SDK, 광고 SDK가 없습니다. 개발자는 사용자의 API Key, 웹페이지 텍스트, 선택한 텍스트, 브라우징 기록, 번역 기록 또는 토큰 기록을 수신하거나 판매하거나 데이터 중개업체에 제공하지 않습니다.

5. 보관 및 삭제

  • 설정과 기록은 사용자의 로컬 브라우저에만 저장되므로 정해진 클라우드 보관 기간이 없습니다.
  • 번역 기록은 최대 500개를 보관하며 전체 용량은 약 4 MiB로 제한됩니다. 토큰 기록은 최대 1,000개를 보관하며 전체 용량은 약 512 KiB로 제한됩니다. 한도를 초과하면 오래된 기록부터 삭제됩니다.
  • 대시보드에서 번역 기록을 개별 삭제하거나, 전체 번역 기록을 삭제하거나, 토큰 기록을 삭제하거나, API Key를 제거할 수 있습니다.
  • 확장 프로그램을 제거하면 일반적으로 Chrome이 저장한 로컬 데이터도 삭제됩니다. 확실하게 삭제하려면 확장 프로그램을 제거하기 전에 대시보드에서 기록과 키를 삭제하세요.

6. 권한 사용 방법

  • activeTab: 사용자가 확장 프로그램을 조작할 때만 현재 탭에 접근합니다.
  • scripting: 로컬 읽는 법, 외래어 원어 주석, 선택 영역 번역 인터페이스를 현재 페이지에 삽입합니다.
  • storage: 설정, 기록, 토큰 기록을 로컬에 저장합니다.
  • 선택적 호스트 권한: API 설정을 저장하거나 테스트할 때만 사용자가 지정한 API 출처에 대한 네트워크 접근을 요청합니다. 확장 프로그램은 모든 사이트에 접근하는 고정 권한을 미리 받지 않습니다.

7. 보안 경계

API Key는 대시보드나 백그라운드 응답에 전체가 표시되지 않으며, 확장 프로그램 저장소는 신뢰할 수 있는 확장 프로그램 컨텍스트로 접근이 제한됩니다. 이러한 조치는 우발적인 노출을 줄이지만 로컬 확장 프로그램 저장소는 하드웨어 기반 보안 저장소가 아닙니다. 브라우저 프로필과 기기 계정을 보호하고, 키가 노출되었다고 의심되면 즉시 제공업체에서 키를 폐기하거나 교체하세요.

8. 아동, 변경 사항 및 문의

확장 프로그램은 아동을 위해 특별히 설계된 서비스가 아니며 사용자 계정을 적극적으로 생성하지 않습니다. 기능이나 데이터 처리 방식이 중대하게 변경되면 이 방침의 날짜와 설명을 업데이트합니다. 개인정보 관련 문의는 공개 프로젝트의 GitHub Issues를 통해 제출할 수 있습니다.
