PRIVACY POLICY

プライバシーポリシー

本ポリシーでは、日本語漢字読み方アシスタント（以下「本拡張機能」）が処理するデータ、その目的、およびユーザーが管理・削除する方法を説明します。

発効日および最終更新日：2026年8月22日

1. 単一の目的

本拡張機能は、日本語ウェブページの漢字に読みを表示し、高信頼度のカタカナ外来語に原語を表示します。また、ユーザーが能動的に選択したテキストを、ユーザーが設定した OpenAI 互換 API で翻訳します。広告、プロファイリング、データ販売、その他の読解支援と無関係な目的には使用しません。

2. ローカルで処理するデータ

  • ウェブページ本文は、読みを生成するためブラウザー内で日本語形態素解析を行います。この処理でページ本文が開発者サーバーへ送信されることはありません。
  • カタカナ外来語は、拡張機能に同梱された固定の語源サブセットと手作業で整備した一般的な補正に対してローカルで照合されます。リモート辞書の照会や翻訳 API の呼び出しは行いません。
  • API Key、BaseURL、モデル、翻訳先言語、表示言語は Chrome 拡張機能ストレージにローカル保存されます。
  • 翻訳履歴には選択した原文、翻訳文、ページ URL、ページタイトル、時刻、モデル、翻訳先言語、Token 使用量を含む場合があります。Token 詳細にはページ URL、ページタイトル、時刻、使用量が含まれます。これらの記録はローカルに保存されます。

3. ユーザーが選んだ提供者へ送信するデータ

ユーザーが翻訳を実行した場合に限り、選択テキスト、翻訳先言語、必要な指示が設定済みの API BaseURL へ送信されます。API Key は HTTPS リクエストの認証情報として提供者に送信されます。「接続をテスト」を押すと固定のテスト文「こんにちは」を送信します。ページ URL、ページタイトル、ローカル履歴は翻訳リクエストに付加しません。

リモート提供者は自身の規約とプライバシーポリシーに基づき受信データを処理します。信頼できるサービスだけを設定し、保存、学習、越境移転の扱いを確認してください。ローカル以外のエンドポイントは HTTPS を使用し、HTTP を使用できるのは localhost と 127.0.0.1 のみです。

4. 開発者はデータを収集・販売しません

本拡張機能には、開発者が運用するデータ受信サーバー、分析 SDK、広告 SDK はありません。開発者は、API Key、ページ本文、選択テキスト、閲覧履歴、翻訳履歴、Token 記録を受け取らず、販売またはデータブローカーへ提供しません。

5. 保存期間と削除

  • 設定と記録はローカルブラウザーにのみ保存されるため、固定のクラウド保存期間はありません。
  • 翻訳履歴は最大500件、合計約4 MiBまでです。Token 記録は最大1,000件、合計約512 KiBまでです。上限を超えた場合は古い記録から削除されます。
  • ダッシュボードでは、個別の履歴削除、全履歴の消去、Token 記録の消去、API Key の削除ができます。
  • 拡張機能を削除すると、通常は Chrome が保存したローカルデータも削除されます。確実に削除するには、削除前にダッシュボードで記録と Key を消去してください。

6. 権限の利用方法

  • activeTab: ユーザーが拡張機能を操作した場合に限り、現在のタブへアクセスします。
  • scripting: 現在のページにローカルの読み、外来語原語注釈、選択範囲翻訳の画面を挿入します。
  • storage: 設定、履歴、Token 記録をローカルに保存します。
  • 任意のホスト権限: API 設定の保存またはテスト時に限り、ユーザー指定の API オリジンへのネットワークアクセスを要求します。すべてのウェブサイトへ恒久的にアクセスする権限は取得しません。

7. セキュリティ上の境界

API Key がダッシュボードやバックグラウンド応答に完全な形で表示されることはなく、拡張機能ストレージへのアクセスは信頼できる拡張機能コンテキストに制限されます。これらは偶発的な露出を減らしますが、ローカル拡張機能ストレージはハードウェア金庫ではありません。ブラウザープロファイルと端末アカウントを保護し、漏えいの疑いがある場合は直ちに提供者側で Key を失効またはローテーションしてください。

8. 子ども、変更、お問い合わせ

本拡張機能は子ども向けに特別設計されたサービスではなく、ユーザーアカウントを積極的に作成しません。機能またはデータ処理の実務が大きく変更された場合は、本ポリシーの日付と説明を更新します。プライバシーに関する質問は公開プロジェクトの GitHub Issues から送信できます。
