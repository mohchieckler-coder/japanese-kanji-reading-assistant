概要

調べものによる中断を減らし、読書の流れを保つ

これはページを置き換えるリーダーではありません。今見ているページにいつでも追加・削除できる軽量な日本語読解支援です。

01

日本語ウェブページを開く

ニュース、掲示板、学術、スポーツなどの通常のページで使えます。本文やリンクを置き換えず、現在のページに直接支援情報を追加します。

02

読みを有効にする

拡張機能はブラウザー内で本文をローカル解析し、標準の ruby マークアップで漢字の上に読みを表示します。

03

必要なときだけ翻訳する

語、文、段落を選択し、タブを何度も切り替えることなく同じページで翻訳を確認できます。

機能

実際のウェブページを読むために設計

一般的な漢字や外来語の語源から、ニュースの日付、人名、長文の翻訳まで、すべての機能は元のページ構造を保つように作られています。

01 · スマートな読み

漢字ごとの読みを上に表示

Kuromoji がブラウザー内で形態素解析をローカル実行します。後から読み込まれた内容も処理し、もう一度クリックすると拡張機能が追加した読みを取り除きます。

  • コード、フォーム、既存の ruby マークアップは処理しません
  • 日付、外来語、一般的な文脈は慎重に曖昧性を解消します
  • 漢字だけに読みを付け、送り仮名はそのまま保ちます
  • 本文の長い読みは縮小し、ヘッダーとナビゲーションの幅を安定させます
  • スタイルと操作性を保つため、要素階層を組み替えません

02 · 外来語の語源

カタカナの上に外国語の原語を表示

ポップアップには「外来語の語源を表示」ボタンがあります。有効にすると、拡張機能は同梱された3,353件のローカル語源記録で高信頼度の外来語を照合し、著名な外国の指導者・公的人物・地名の原表記を表示します。API は呼び出さず、ページ本文もアップロードしません。

  • 英語の項目は国名表示を付けず、原語だけを示します
  • 他言語は仏・独・西など、日本語の漢字による国名略称を使います
  • 長い注釈はカタカナ本文の幅に折り畳まれ、幅を制限したポップオーバーで展開します
  • 完全な固有名詞は直接照合できますが、略称には役職・国・人物の文脈が必要です
  • 同形語、和製英語、未知の語は慎重に処理対象から外します

語源データは JMdict に由来し、EDRDG General Dictionary Licence Statement および CC BY-SA 4.0 に従います。

長い原表記は、折り畳んだ要約として表示されます。行間を広げずに原表記の全文をポップオーバーで確認するには、クリックするか、Enter または Space キーを押します。

03 · 選択範囲の翻訳

語・文・段落を翻訳

一般名を推測せず、公的人物名を確認

プライバシー

ページ本文はローカルに留まり、翻訳する内容は自分で決められます

日本語の読みと外来語の語源照合は、常にブラウザー内でローカル処理されます。ページ内容のうち、ユーザーが能動的に選択したテキストだけを、設定した翻訳サービスへ送信します。接続テストでは固定のテスト文「こんにちは」を送信します。

プライバシーポリシー全文を読む

  • 01

    API Key は端末内に保存信頼できる拡張機能コンテキストに保存し、完全な形では表示しません

  • 02

    API 権限は必要時に要求すべてのウェブサイトの API に恒久的にアクセスする権限は取得しません

  • 03

    履歴は自分で管理翻訳履歴と Token 記録はいつでも消去できます

よくある質問

始める前に知っておきたいこと

本拡張機能はローカル処理を優先し、必要な場合にだけ接続するため、読み機能と翻訳機能をそれぞれ独立して利用できます。

読み機能に API は必要ですか？＋

いいえ。漢字の読みはブラウザー内でローカル解析されます。ご自身の互換 API が必要なのは選択範囲の翻訳だけです。

ウェブページ全体をアップロードしますか？＋

いいえ。読みの注釈にネットワークは使用しません。ページ内容のうち、ユーザーが能動的に選択したテキストだけを、設定した翻訳サービスへ送信します。「接続をテスト」をクリックすると、固定のテスト文「こんにちは」を送信します。提供者は自身のプライバシーポリシーに基づいてデータを処理します。

現在のページから読みを削除するには？＋

拡張機能のポップアップをもう一度開き、「読みを削除」をクリックします。拡張機能が生成した ruby マークアップを削除して元のテキストを復元しますが、選択範囲の翻訳は引き続き利用できます。動的な変化が特に多い一部のページでは、再読み込みが必要になる場合があります。

原語が表示されないカタカナ語があるのはなぜですか？＋

カタカナは和製英語、擬音語、固有名詞にも使われます。本拡張機能が注釈を付けるのは、2026-08-17 版の高信頼度な固定 JMdict サブセット、手作業で確認した一般語レイヤー、選択的に確認した国立国語研究所の語彙表に基づく、語源が明確で検証済みの語だけです。項目をまたぐ同形語、未知語、安全な文脈のない人名の略称は変更しません。英語は原語だけを表示し、その他の言語と外国固有名詞には「仏」「独」「西」など日本語の国名略称を使います。

現在処理できないページや要素は？＋

Chrome のシステムページには拡張機能を挿入できません。閉じた Shadow DOM、クロスオリジンの iframe、まれな文字、未知の固有名詞は変更されない場合があります。コードブロック、フォーム、既存の ruby マークアップ、編集可能な領域は意図的に処理しません。

翻訳 API には何が必要ですか？＋

API は POST /chat/completions に対応している必要があります。通常のサービスでは HTTPS を使用し、HTTP を使用できるのは localhost と 127.0.0.1 だけです。各リクエストは12,000文字までで、ご自身の Key、ネットワーク、クォータ、モデルへのアクセス状況に依存します。ローカルの Token 記録は推定値であり、提供者の請求額を示すものではありません。
