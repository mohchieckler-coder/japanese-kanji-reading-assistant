Overview

Less time breaking your flow to look things up

This is not a replacement reader. It is a lightweight Japanese aid that you can add to or remove from the current page at any time.

01

Open a Japanese webpage

Use it on ordinary news, forum, academic, or sports pages. The extension adds help directly to the current page without replacing the entire page body or its links.

02

Turn on readings

The extension analyzes text locally in your browser and displays readings above kanji with standard ruby markup.

03

Translate only when needed

Select a word, sentence, or paragraph and view its translation on the same page without repeatedly switching tabs.

Features

Designed for reading real webpages

From ordinary kanji and loanword origins to news dates, names, and long-sentence translation, every feature is built to preserve the original page structure.

01 · Smart readings

See readings above kanji at a glance

Kuromoji performs morphological analysis locally in the browser. Content loaded later is also processed, and clicking again removes the readings added by the extension.

  • Skips code, forms, and existing ruby markup
  • Conservative disambiguation for dates, loanwords, and common contexts
  • Adds readings only to kanji and keeps okurigana intact
  • Shrinks long body-text readings while keeping header and navigation widths stable
  • Avoids rearranging element hierarchy to preserve styles and interactions

02 · Loanword origins

See original foreign words above katakana

The popup includes a separate “Show loanword origins” button. When enabled, the extension uses 3,353 bundled local etymology records to match high-confidence loanwords and display original forms for well-known foreign leaders, public figures, and places. It makes no API call and does not upload page text.

  • English entries show only the original word, without a country marker
  • Other languages use Japanese kanji country abbreviations such as 仏, 独, and 西
  • Long annotations collapse to the katakana base width and expand in a width-limited popover
  • Full proper names can match directly; shortened names require role, country, or person context
  • Homographs, wasei-eigo, and unknown words are conservatively skipped

Etymology data is derived from JMdict under the EDRDG General Dictionary Licence Statement and CC BY-SA 4.0.

FAQ

What you may want to know before starting

The extension is local-first and connects only when needed, so readings and translation can be used independently.

Do readings require an API?＋

No. Kanji readings are analyzed locally in your browser. Only selection translation requires your own compatible API.

Does the extension upload the entire webpage?＋

No. Reading annotations do not use the network. Of the page content, only text you actively select is sent to your configured translation service. Clicking “Test connection” sends the fixed text “こんにちは”. The provider processes data under its own privacy policy.

How do I remove readings from the current page?＋

Open the extension popup again and click “Remove readings”. The extension removes its generated ruby markup and restores the original text, while selection translation remains available. A small number of highly dynamic pages may require a refresh.

Why do some katakana words have no original form?＋

Katakana can also represent wasei-eigo, onomatopoeia, or proper names. The extension annotates only verified words with clear origins, using a fixed high-confidence JMdict subset dated 2026-08-17, a manually reviewed common-word layer, and selectively checked National Institute for Japanese Language and Linguistics vocabulary lists. Cross-entry homographs, unknown words, and shortened names without safe context remain unchanged. English shows only the original word; other languages and foreign proper names use Japanese country abbreviations such as 仏, 独, and 西.

Which pages cannot be processed yet?＋

Extensions cannot be injected into Chrome system pages. Closed shadow DOM, cross-origin iframes, rare characters, and unknown proper names may remain unchanged. Code blocks, forms, existing ruby markup, and editable areas are deliberately skipped.

What must a translation API support?＋

The API must support POST /chat/completions. Remote services must use HTTPS; only localhost and 127.0.0.1 may use HTTP. Each request is limited to 12,000 characters and depends on your own key, network, quota, and model access. Local token records are estimates and are not the provider's bill.
