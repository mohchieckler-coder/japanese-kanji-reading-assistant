产品介绍

少一点查词中断，多一点连续阅读

它不是替换网页的阅读器，而是一层轻巧、可随时开启和移除的日语辅助。

01

打开日语网页

适用于新闻、论坛、学术和体育等普通网页，直接在当前页添加辅助信息，不替换整页正文或链接。

02

点击启用读音

插件在浏览器本地分析正文，并以标准 ruby 标记在汉字上方显示读音。

03

需要时再翻译

主动选中词、句子或段落，在当前页面查看译文，不必频繁切换标签页。

核心功能

为真实网页阅读而设计

从普通汉字到外来语原词、新闻日期、人物姓名，再到长句翻译，每项能力都以保留原网页结构为前提。

01 · 智能注音

汉字上方，一眼看到读音

Kuromoji 在浏览器本地完成形态分析。动态加载的正文也会继续处理，再次点击会移除插件生成的注音。

  • 跳过代码、表单和已有 ruby
  • 日期、外来词与常见语境的保守消歧
  • 只给汉字注音，送り仮名保持原文
  • 正文长读音自适应缩小，页头／导航注音不改变项目宽度
  • 不重排元素层级，尽量保留样式与交互

02 · 外来语原词

片假名上方，看见外语原词

弹窗提供独立的“外来语原词标注”按钮。点击后，插件会用随包的 3,353 项本地词源记录匹配高置信外来语，并显示常见外国政要、名人与地名的原文；不调用 API，也不会上传网页正文。

  • 英语只显示原词，不附加国家标记
  • 其他语言使用日语汉字国名简称：仏、独、西等
  • 长标注按片假名基底宽度折叠，点击后在限宽浮层完整显示
  • 完整专名可直接匹配，简称须有职务、国家或人物上下文
  • 同形异义、和制英语与未知词保守跳过

词源数据派生自 JMdict，遵循 EDRDG General Dictionary Licence Statement 与 CC BY-SA 4.0。

常见问题

开始之前，你可能想知道

插件坚持“本地优先、按需联网”，因此读音和翻译可以独立使用。

使用读音功能必须配置 API 吗？＋

不需要。汉字读音由插件在浏览器本地分析；只有划词翻译需要你配置自己的兼容接口。

插件会把整篇网页上传吗？＋

不会。正文注音不联网；网页内容方面，只有主动选中的文字会发送给所配置的翻译服务。点击“测试连接”时会发送固定文本“こんにちは”，服务商的数据处理受其自身隐私政策约束。

如何移除当前页面的读音？＋

再次打开扩展弹窗并点击“移除读音”。插件会移除生成的 ruby 并恢复原文，划词翻译仍可继续使用；极少数高度动态的页面可能需要刷新。

为什么有些片假名没有显示外语原词？＋

片假名也可能是和制英语、拟声词或专名。插件使用 2026-08-17 固定的 JMdict 高置信子集、人工复核常用词层和选择性核对的国立国语研究所词表，只标注来源明确的已核实词；跨词条同形异义、未知词及不满足安全上下文的简称会保留原文。英语只显示原词，其他语言与外国专名使用仏、独、西等日语国名简称。

哪些页面暂时无法处理？＋

Chrome 系统页无法注入扩展；封闭 Shadow DOM、跨域 iframe、生僻字和未知专名可能保持原样。代码块、表单、已有 ruby 和可编辑区域会被主动跳过。

翻译接口需要满足哪些条件？＋

接口需兼容 POST /chat/completions。普通服务必须使用 HTTPS，仅 localhost 和 127.0.0.1 可使用 HTTP；每次最多翻译 12,000 个字符，并依赖你自己的 Key、网络、额度与模型权限。本地 Token 记录仅供参考，不等同于服务商账单。
