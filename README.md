# 日语汉字 AI 读音助手

这是一个 Chrome Manifest V3 扩展。用户打开日语新闻等普通网页后，点击扩展按钮，即可在汉字上方显示平假名读音，并对主动选中的词、句子或段落进行翻译。读音始终由浏览器内的本地日语形态分析流程生成；只有用户主动选中的文本才会发送到用户自行配置的 OpenAI 兼容接口。

## 使用方法

```powershell
npm install
npm test
```

然后：

1. 打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目的 `dist` 目录。
5. 打开一个日语网页，点击工具栏中的“日语汉字 AI 读音助手”，再点击“启用当前页读音与划词翻译”。

如果此前已经加载过本项目，每次执行 `npm run build` 后都要在 `chrome://extensions/` 对该扩展点击“重新加载”，再刷新已经打开的日语网页。2.0.1 起，弹窗检测到 Chrome 缓存版本与磁盘文件不一致时，会显示“立即重新加载扩展”。优先使用重载，不要直接移除扩展；移除会清空该扩展 ID 下保存的 API 配置、历史和 Token 记录。

如果工具栏没有直接显示图标，请点击 Chrome 右上角的拼图按钮，再点击本扩展旁边的图钉将其固定。

再次点击按钮可移除读音标注；划词翻译会在当前页面继续可用。扩展还会自动处理启用后动态加载的正文。

## 划词翻译与管理面板

2.0.0 版新增：

- 选中日语词语、完整句子或段落后，在选区附近点击翻译按钮。
- 结果卡显示目标语言、译文和本次 Token 消耗，支持复制、重试与关闭。
- 管理面板可配置 API Key、BaseURL、模型和目标语言，并查看/搜索/删除翻译历史及按日汇总的 Token 记录。
- 支持 OpenAI 兼容的 `POST /chat/completions` 接口；默认 BaseURL 为 `https://api.openai.com/v1`，Key 由用户自行填写。

2.0.1 修复了扩展文件更新后 Chrome 仍运行旧清单所导致的管理面板打不开和划词翻译失效：弹窗会识别混合版本并提供一键重载，内容脚本也会替换旧版控制器并清理残留的翻译浮层。后台初始化出现瞬时失败时会自动重试。

2.1.0 为翻译管理面板新增中文、English、日本語、한국어四种界面语言。可在面板右上角切换，选择会保存在本机并在下次打开时恢复。界面语言与“翻译目标语言”是两项独立设置：切换管理面板语言不会改变译文的目标语言。

2.2.0 将同一套四语言界面扩展到浏览器工具栏弹窗。可直接在弹窗顶部切换语言，管理面板随后会保持同步；从管理面板切换后，重新打开弹窗也会使用新语言。弹窗会按当前界面语言显示读音状态、翻译配置、目标语言、升级重载及错误提示。

2.3.0 新增中国、韩国／朝鲜和越南现代人物的高置信姓名注音。已核验的完整姓名会作为一个整体标注当地发音，例如 `金正恩=キム・ジョンウン`、`習近平=シージンピン`、`阮富仲=グエン・フー・チョン`；网页已明确提供的括号读音优先。短姓名和同形词必须命中国别或人物职务上下文，`胡志明市`、`李強化策` 等地点或普通词不会套用人名规则。姓名被内联标签拆开时会保留原 DOM，并对各安全片段协同标注，不按单字猜读音。

配置方法：打开扩展弹窗，点击“打开翻译管理面板”，填写 BaseURL、模型和 API Key 后保存。普通服务必须使用 HTTPS；只有 `localhost` 或 `127.0.0.1` 本地服务允许 HTTP。浏览器只会请求当前 BaseURL 主机的可选网络权限，切换服务地址后会尽力移除旧主机权限。

API Key 只保存在 `chrome.storage.local` 的可信扩展上下文中，管理面板和网页都拿不到保存后的完整 Key。Key 不会写入翻译历史、Token 记录或错误信息。历史与用量均为本机数据，可在面板中清空。为了避免误传，每次最多翻译 12,000 个字符；不要选中不希望发送给接口的敏感内容。

新闻日期中的星期缩写会按上下文读音处理，例如 `(日)=にち`、`（月）=げつ`、`(火)=か`，同时不会改变普通词语中“日/月”等汉字的读法。

数字月份会按日历语义处理，例如 `8月` 中“月”读“がつ”；天气栏目式 `/雨・風` 中的“雨”读“あめ”，而“雨量、豪雨、梅雨、酸性雨”等复合词仍使用各自的词典读音。

1.1.0 版进一步支持：

- 新闻和赛程中的特殊日期读法，例如 `20日=はつか`、`24日=にじゅうよっか`，并把数字与“日”作为一个完整 ruby 标注。
- `1人/一人=ひとり`、`2人/二人=ふたり`，以及 `六回=ろっかい` 等不规则计数读法。
- 学术、医学、体育和社区网页中经真实页面确认的高置信固定词组，例如 `博士課程=はくしかてい`、`協働=きょうどう`、`昨夏=さっか`、`既読=きどく`。
- 日期和星期被网页拆到相邻 `span/strong/time` 标签时的星期消歧；上下文扫描有字符、节点和块级边界限制，不会跨段拼接正文。

## 开发命令

- `npm run build`：生成可加载的 `dist` 扩展。
- `npm run test:unit`：验证读音逻辑、外国人名词典与边界、翻译请求构造、密钥脱敏、权限边界、容量限制及后台消息流程。
- `npm run test:e2e`：在无头 Chromium 中验证真实 DOM 标注、词/句/段翻译、管理面板、动态内容、关闭/重开和防重复注入。
- `npm run test:extension`：加载真实 Manifest V3 扩展，验证 Service Worker、管理面板、划词消息、OpenAI 兼容请求、译文及 Token 返回。
- `npm run audit:live`：在新闻、体育、论坛与学术网站上执行真实页面兼容性审计，并输出 `artifacts/live-site-audit.json`。
- `npm run validate`：检查 Manifest、构建文件和本地词典完整性。
- `npm test`：依次执行全部构建与验证。

## 设计边界

- 不修改 `script`、表单控件、代码块、已有 `ruby` 和可编辑区域。
- 词典无法识别的生僻字或新造专名会原样保留，避免显示猜错的读音。
- Chrome 系统页（例如 `chrome://settings`）禁止扩展注入脚本，不能标注。
- 划词翻译依赖用户自己的兼容 API 配置、网络、额度与模型权限；项目不会创建、内置或上传 API Key。
- 当前版本处理主文档及其后续动态内容，不处理封闭 Shadow DOM 或跨域 iframe。
- 相邻标签不会被重排或合并；日期等规则使用受限上下文，已核验外国姓名按原标签中的安全片段分别生成 ruby，从而保留站点事件、CSS 与关闭插件后的 DOM 结构。
